# Product Image Specifications

## Recommended Image Specifications for Qualitick Collections

### **File Format**
- **Primary Formats**: JPG/JPEG, PNG, WebP
- **Preferred**: JPG/JPEG (best balance of quality and file size)
- **Use PNG**: When transparency is needed (logos, watermarks)
- **Use WebP**: For modern browsers (better compression, smaller file size)

### **File Size**
- **Maximum per image**: 10 MB
- **Recommended per image**: 500 KB - 2 MB
- **Optimal**: Under 1 MB for fast loading

### **Dimensions**
- **Minimum**: 800 x 800 pixels
- **Recommended**: 1200 x 1200 pixels (1:1 aspect ratio for square)
- **Maximum**: 3000 x 3000 pixels
- **Aspect Ratio**: 
  - Square (1:1) - Recommended for product thumbnails
  - 4:3 or 16:9 - Acceptable for product detail images

### **Image Quality**
- **Resolution**: 72-150 DPI (web standard)
- **Color Space**: sRGB
- **Compression**: 
  - JPG: Quality 80-90% (good balance)
  - PNG: Use PNG-24 for photos, PNG-8 for graphics
  - WebP: Quality 80-85%

### **Multiple Images**
- **Minimum**: 1 image (required)
- **Recommended**: 3-5 images per product
- **Maximum**: 10 images per product
- **Image Order**: 
  1. Main product image (front view)
  2. Side view
  3. Detail/close-up shots
  4. Lifestyle/context images
  5. Back view

### **Technical Requirements**
- **File Naming**: Use descriptive names (e.g., `rolex-submariner-front.jpg`)
- **No Spaces**: Use hyphens or underscores instead
- **Orientation**: Correct orientation (not rotated)
- **Background**: 
  - White or transparent background preferred
  - Consistent background across all product images
- **No Watermarks**: Product images should not have watermarks (unless branding)

### **Content Guidelines**
- **Sharp Focus**: Product should be in sharp focus
- **Good Lighting**: Well-lit, no harsh shadows
- **Centered**: Product should be centered in frame
- **No Text Overlays**: Avoid text overlays on product images
- **High Quality**: No pixelation, blur, or compression artifacts

### **Best Practices**
1. **Consistency**: All product images should have consistent style
2. **Multiple Angles**: Show product from different angles
3. **Detail Shots**: Include close-ups of important features
4. **Context**: Lifestyle images showing product in use
5. **Optimization**: Compress images before upload to reduce file size
6. **Responsive**: Images should look good on mobile and desktop

### **Tools for Image Optimization**
- **Online Tools**: TinyPNG, Squoosh, ImageOptim
- **Desktop**: Photoshop, GIMP, Affinity Photo
- **Command Line**: ImageMagick, Sharp

### **Current System Limitations**
- Currently accepts: PNG, JPG up to 10MB
- Multiple images allowed
- Images stored as URLs (not file uploads yet)
